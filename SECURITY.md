# Security

If you discover a security or privacy issue in Salam, do not include sensitive user data in a public issue.

Please report security concerns privately to the project maintainer and include:

- a concise description of the issue
- affected component or area
- reproduction steps, when safe to provide
- potential impact

Do not include real user mental-health text, personally identifiable information, credentials, API keys, or other sensitive data in reports.

Salam is designed with privacy-by-design principles, and user-provided text should be treated as potentially sensitive.
